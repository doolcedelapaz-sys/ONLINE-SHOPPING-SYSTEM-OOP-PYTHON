# ONLINE-SHOPPING-SYSTEM-OOP-PYTHON
Object-Oriented Programming (OOP) implementation of an online shopping system in Python including product catalog management, shopping cart, payment processing, inventory control and delivery services.

## Features

### Product Catalogue
- Electronics products
- Book products
- Inventory management
- Product classification

### Electronics Category
- Computers
- Tablets
- Smartphones
- Warranty information
- Stock management

### Books Category
- Computer Science
- Mathematics
- Economics
- ISBN tracking
- Author and publisher information

### Shopping Cart
- Add products
- Display cart contents
- Clear cart
- Total order calculation

### Payment System
- Payment card validation
- Balance verification
- Secure customer information

### Delivery Services
- Shipping cost calculation
- Free shipping for orders above $100
- Delivery address management

## OOP Concepts Implemented

- Classes and Objects
- Inheritance
- Polymorphism
- Encapsulation
- Constructors (__init__)
- Instance Variables
- Class Hierarchies
- Method Overriding
- Getters and Setters
